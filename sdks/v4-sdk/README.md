# Ring Protocol V4 SDK

This historical compatibility package is maintained in `RingProtocol/sdks`. It uses `@ring-protocol/sdk-core` and the FEW-aware `@ring-protocol/v2-sdk`; ordinary V2 compatibility is provided separately by `@ring-protocol/uniswap-v2-sdk`.

Follow the root README for development: Node 22.14 or newer, Yarn 3.2.3, and root-level `yarn install`, `yarn g:build`, and `yarn g:test`. To run this package's tests after building the graph, use `yarn sdk @ring-protocol/v4-sdk test`.

The local `1.0.0` version is a review candidate. Including this package does not imply V4 deployment or routing support on Robinhood.
